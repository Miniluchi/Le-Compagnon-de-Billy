# BillyHelper

Compagnon de lecture pour les livres-jeux *Les aventures du Pyro-Barbare et de Billy* de Bob Lennon :
feuille de personnage, dés et assistant de combat, sur téléphone comme sur ordinateur.

**Application en ligne : https://miniluchi.github.io/BillyHelper/**

Seul le tome 1, *La Forteresse du Chaudron Noir*, est géré pour l'instant. Il faut le livre pour jouer :
l'application ne contient aucun texte des chapitres.

- [`app/`](app) : l'application (React, TypeScript, Vite, PWA hors ligne).
- [`docs/`](docs) : les règles du jeu telles que l'application les applique, et le cahier des besoins.

Projet de fan, non officiel.
