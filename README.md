# BillyHelper

Compagnon de lecture pour les livres de Bob Lennon : _Les aventures du Pyro-Barbare et de Billy_ :
feuille de personnage, dés, assistant de combat et succès, sur téléphone comme sur ordinateur.

**Application en ligne : https://miniluchi.github.io/BillyHelper/**

Il faut le livre pour jouer : l'application ne contient aucun texte des chapitres.

## Livres pris en charge

- **Tome 1, _La Forteresse du Chaudron Noir_** : pris en charge.
- **Tomes suivants** : Je ne l'est ai pas encore vérifiés.

## Sauvegarde

- **Sur l'appareil** : les parties et les succès sont enregistrés automatiquement dans le navigateur, et l'application marche hors ligne.
- **Export / import** : un fichier JSON à télécharger depuis les réglages, pour garder une copie ou changer d'appareil à la main.
- **Synchronisation (facultative)** : en se connectant avec un compte Google dans les réglages, la progression est synchronisée entre ses appareils via Firebase (Google), hébergé dans l'UE. Les données restent aussi sur l'appareil, et un bouton permet de supprimer sa sauvegarde cloud.

Projet de fan, non officiel.
